# SZR College — Frontend

Next.js 16 / React 19 app for the SZR College platform. See the [root README](../README.md) for project overview, architecture, and setup instructions.

## Quick commands

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

Reads `NEXT_PUBLIC_API_URL` (defaults to `http://127.0.0.1:8000`) to reach the FastAPI backend.
